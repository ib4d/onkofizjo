# onkofizjo

Mobile-first foundation for the onkofizjo ecosystem: a bilingual public website and the first responsive CRM shell for Małgorzata Papierz.

## Current foundation

- Polish / English language switch.
- Public marketing website without contact or booking forms.
- Phone-first booking call to action.
- Responsive CRM demonstration shell.
- Separate service ecosystems: oncology rehabilitation, physiotherapy, dietetics, massage and home visits.
- First concept for the dietetic assistant and evidence-backed AI layer.

## Local preview

Open `index.html` in a browser. This first vertical is intentionally dependency-free so the product direction can be tested before wiring authentication, database, documents and agent services.

## Next implementation slice

1. Real app shell and routing.
2. Authenticated CRM with role-based access.
3. Database schema for patients, appointments, consent and audit events.
4. Diet-plan builder with versioning and human approval.
5. Controlled knowledge base and retrieval-backed assistants.
