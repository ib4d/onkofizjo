# Onkofizjo · Fase 8

## Alcance actual

Fase 8 prepara la distribución pública de marketing sin indexar el CRM ni
exponer datos clínicos. No se ha publicado todavía un dominio nuevo ni se ha
activado analítica.

## Implementado

- `robots.txt` permite marketing y bloquea CRM, API y rutas clínicas.
- `sitemap.xml` contiene únicamente páginas públicas y usa el dominio público
  actual `reha.mp` como referencia provisional.
- `manifest.webmanifest` define instalación básica y metadatos PL.
- `stitch-marketing.html` incluye descripción, canonical, hreflang PL/EN y
  manifest.
- `SEO_RELEASE_CHECKLIST.md` define la evidencia requerida antes de publicación.
- La sustitución del dominio provisional es una puerta obligatoria antes de
  enviar el sitemap a buscadores.

## Pendiente

Dominio definitivo, canonical/hreflang final, consentimiento de analítica,
Search Console, despliegue HTTPS, revisión legal de copy y publicación masiva.
